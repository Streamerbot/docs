---
title: Deck Notify
description: Send a notification to a Streamer.bot deck
version: 1.0.0
parameters:
  - name: Deck
    type: Select
    description: Select the deck to send the notification to
    required: true
  - name: Title
    type: Text
    description: The title of the notification
    required: true
  - name: Description
    type: Text
    description: The description text for this notification
---

::note
[Streamer.bot Website Integration](/guide/integrations/streamerbot) is required for this sub-action
::
