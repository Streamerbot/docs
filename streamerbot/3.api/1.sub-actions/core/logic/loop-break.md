---
title: Loop Break
description: Break out of a loop in the current action.
version: 1.0.5
---

As opposed to the [Break](/api/sub-actions/core/logic/break) sub-action, which will break out of the current action entirely, this sub-action will only break out of the current loop and continue executing the rest of the action.
