::important
**Streamer.bot is a portable application** and does not require installation.
<br>
Simply download the latest version, extract it to your desired location, and run `Streamer.bot.exe`!
::

## First Time Setup

::collapsible{name="Video Tutorial"}
:youtube-embed{id="s_h9IPNLme0"}
::

::steps{level=3}

### Download Streamer.bot

Navigate to the [Streamer.bot Downloads](https://streamer.bot/downloads){target=_blank} page and download the latest stable version of Streamer.bot.

:::card-group{.mt-3 .mb-3}
::::card{icon=i-mdi-download title="Streamer.bot" to=https://streamer.bot/downloads target=_blank}
Download the latest stable version of Streamer.bot
::::
:::

### Extract the Archive

Extract the `.zip` archive to your desired location.

:::warning
Avoid synced storage, such as OneDrive, Google Drive, etc, as these can cause unexpected issues.
:::

Streamer.bot is a **portable** application, no further installation is needed!

### Run Streamer.bot.exe

Open the directory where you chose to extract the archive and execute `Streamer.bot.exe`!

:::success
**Streamer.bot should now be up and running!**
:::

:::warning
It is **not recommended** to run Streamer.bot as administrator.
<br>
This may cause issues down the line especially if you start as admin once and later change it.
<br>
The included C# compiler can also run custom code, which can be a security risk if you are not careful.
:::
::

## Updating

::important
**Streamer.bot has a built-in auto updater** that will automatically check for updates and prompt you to update when new versions are available.
::

By default, Streamer.bot will automatically check for `stable` releases, but you can optionally receive `alpha` or `beta` releases by connecting the [Streamer.bot Website Integration](/guide/integrations/streamerbot) and changing the `Release Channel` in the updater dialog.

::collapsible{name="Video Tutorial"}
:youtube-embed{id="R51_CW15e3U"}
::

::steps{level=3}

### Check for Updates

Click the `Menu` :icon{name=i-mdi-menu} button in the top-left corner of Streamer.bot, and select `Check for Updates` to open the updater dialog.

:::success
If an update is available, you will be prompted to download and install it automatically.
:::

### Change Update Channel (Optional)

In the top-right corner of the dialog, select your desired `Update Channel`

:::callout{icon=mdi:discord}
Early-access **Beta** releases are available to **everyone** with the `Beta Testers` role in Discord
:::
:::callout{icon=i-simple-icons-patreon}
Early-access **Alpha** releases are available to **Bronze Tier** subscribers on [Patreon](https://patreon.com/nate1280){target=_blank}
:::
::
